Start here: how to read this report

This page explains execution time and memory. Use the main benchmark report for accuracy, F1 and model comparisons. Model summary lists run or stage training times. Epoch Breakdown lists individual epoch times. The ZIP includes training-clock.csv for all recorded models and seeds.

1. Choose a run below. The model, seed, stage and epoch selectors narrow the analysis. A seed is a repeat; a stage is a progressive training step. A controller manages the run; an official-model worker performs training in a separate process. Select the worker to see its training operations.

2. Overview: see when work happened, where measured time went and which memory samples exist. Epoch Breakdown: inspect one training round. GPU Kernels: inspect detailed traces if captured.

3. Save selected summary as PDF: exports only the selected process. Unavailable means no measurement, not zero. Overlapping timeline bars and controller/worker times must not be added together.
