# Model registry

`from efficientgraphbench.models.metadata import get_model, list_models`. Metadata includes source, runner, environment, supported tasks, paper and readiness. `egbench models graphormer` shows UNSUPPORTED_TASK. Primary graphgps and sgformer launch official repositories; experimental variants remain explicit. `models="all"` means the primary list, not experimental alternatives. Inspect runtime result provenance for actual parameter counts and software versions.
