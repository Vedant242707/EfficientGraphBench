# Model registry

`from efficientgraphbench.models.metadata import get_model, list_models`. Metadata includes source, runner, environment, supported tasks, paper and readiness. `egbench models graphormer` shows UNSUPPORTED_TASK. Primary graphgps and sgformer launch official repositories; custom model implementations have been removed. `models="all"` means the primary list, with optional PyG SGFormer available by explicit ID. Inspect runtime result provenance for actual parameter counts and software versions.
